Core Electronics

RTL Design & Simulation using Verilog

Hands-on digital design workshop — from gate-level logic to working FSM-based circuits, simulated and verified on industry-standard tools.

2nd – Final Year2–3 DaysHands-on Lab
Overview

What this workshop covers

Students build a solid foundation in Register Transfer Level (RTL) design using Verilog HDL — the language used across the semiconductor industry to design chips before fabrication. The workshop moves from combinational logic to sequential circuits to finite state machines, with every concept immediately simulated and waveform-verified, not just taught on slides.

Eligibility

Who should attend

Branch
ECE, EEE, CSE (VLSI interest)
Prerequisite
Basic digital logic (gates, flip-flops)
Batch Size
Up to 60 students
Mode
Lab-based, laptop required
Day-wise Plan

Curriculum

D1

Digital Logic to Verilog

  • HDL fundamentals & design flow
  • Combinational circuits: mux, decoder, adder
  • Data types, operators, module structure
  • First simulation on EDA Playground
D2

Sequential Design

  • Flip-flops, registers, counters in Verilog
  • Clock & reset design practices
  • Testbench basics — stimulus & monitoring
  • Waveform debugging using ModelSim
D3

FSM Project Build

  • FSM design methodology (Mealy/Moore)
  • Build a real FSM — traffic light / vending machine
  • Simulate, debug, verify against spec
  • Wrap-up: RTL-to-verification pathway explained
Stack

Tools & technologies used

Verilog HDLModelSimXilinx VivadoEDA Playground
Takeaways

What students walk away with

  • Can write synthesizable RTL from a spec
  • Comfortable reading & debugging waveforms
  • Built one complete FSM-based mini project
  • Understands the chip design flow end-to-end
  • Clear next-step path into Verification (SystemVerilog)

3rd & Final Year2 DaysHands-on Lab
Overview

What this workshop covers

Verification is where most VLSI hiring happens today — this workshop gives final-year students a real look at the role. Students learn why RTL alone isn't enough, how a verification engineer thinks about coverage and corner cases, and build a basic SystemVerilog testbench with classes, randomization, and assertions around a DUT.

Eligibility

Who should attend

Branch
ECE, EEE (VLSI-track students)
Prerequisite
Verilog / RTL basics
Batch Size
Up to 50 students
Mode
Lab-based, laptop required
Day-wise Plan

Curriculum

D1

Why Verification

  • RTL design vs verification — the industry split
  • Limitations of Verilog-only testbenches
  • SystemVerilog OOP basics: classes & objects
  • DUT walkthrough for the workshop project
D2

Building the Testbench

  • Randomization & constraints
  • Interfaces, assertions basics
  • Simple scoreboard & driver-monitor concept
  • Run, debug & interpret coverage output
Stack

Tools & technologies used

SystemVerilogModelSim / QuestaSimEDA Playground
Takeaways

  • Wrote a basic class-based SystemVerilog testbench
